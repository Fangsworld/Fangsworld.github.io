# 回到源头起点学习AI Agent

学习一个复杂事物，典型如 AI Agent，要先回到源头起点。

刚开始时，不要一开始就安装很多 MCP、很多 Agent、很多 Skill。

你们应该先把 Claude 原生的最重要的几个功能逐一熟悉，重点是去 Anthropic 公司的 GitHub 上阅读相关内容。其中，重点阅读：

skills 这个 GitHub 仓库，重点看 Skill 是如何实现的。

以及这几个仓库：

claude-code

claude-code-action

claude-code-base-action

claude-cookbooks

claude-quickstarts

学习要点与忠告
这几个最重要的是这个仓库：claude-cookbooks。

Anthropic的博客也要仔细看看，里面有很多很好的小技巧。

这些例子写得都特别好，一看就是聪明人写的。不愧是年薪百万美元的人，有很多小技巧。

我已经把那些文档都翻译成了中文，这样你们看起来会更清楚。这里面有大量的前沿知识，非常有价值。有不懂的问题要立即提问。可以使用豆包或任意一个可以联网的AI助手，帮助你解释一些术语的含义。千万不要不懂装懂。

这里面还有一个重点，就是你们一定要自己亲自去看文档，不要看太多的二手信息。因为这些东西说白了都太新了。AI大模型技术是在2022年兴起的，近几年又有了新的发展。这样我们在专业上就比别人更深入，未来你们一定会成为该领域的佼佼者。

比如我给大家举一个例子。因为我在家科学上网很不方便，有时候不得不依赖国内信息源进行搜索。结果，我查了一个关于spec-kit的信息。有两篇微信公众号文章都写了两个新功能，提到两个名词。我以为是官方新出的功能，就发给晓霖看。晓霖去官方网站找了半天没找到，最终才发现是AI生成的内容。

官方文档写得最清晰，但第一次使用时往往不太明白，程序员圈里有些“黑话”容易踩坑。但踩了几次坑之后基本就明白了，无非就是配置、路径等老问题，比如路径不对、配置环境不对，这些坑是必须踩的。光听我说不够，千万不要太依赖第三方解释，第三方解释反而容易走弯路。你看，我这么有经验的人都被误导了，那两个功能AI生成得像不像样？看上去特别像是spec-kit应该有的功能。

其实这是假的，真的要踩一次坑之后才明白AI的幻觉问题很严重。为什么我在【认知敏捷法】中一定要做约束？比如说设定四个角色，还有“四加三”的现实约束。因为AI确实存在幻觉问题，信息太多时后面会丢失大量内容，用幻觉生成答案。但如果你反复给AI较小的约束，它反而能记住。这也是反复提醒大家的。
