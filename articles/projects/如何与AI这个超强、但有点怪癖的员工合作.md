# 如何与AI这个超强、但有点怪癖的员工合作？

AI的学习与使用是有门槛的，需要掌握一系列通用技术和工具，否则将被局限在简易界面和流程中，无法充分发挥AI的能力。
这些工具可以分为以下几类：

## 1.计算机基础与开发工具

IDE（集成开发环境）
Terminal/Bash（命令行/终端）
Git/Github（版本控制和代码托管）
API（应用程序接口）
隐藏文件（如 . 开头的配置文件）
Docker（容器化技术）

## 2.标记与数据格式语言

Markdown（轻量级标记语言）
YAML（数据序列化语言，常用于配置）
LaTex（排版系统，用于学术文档）
Mermaid（图表绘制标记语言）
SVG（可缩放矢量图形）
JSON（数据交换格式）

## 3.编程语言及生态

Python
TypeScript
及其庞大的库/框架生态系统

## 4.功能类工具

演示工具：如 Reveal PPT、Slidev
图表库：如 ECharts
视觉化工具
文档转换工具：如 Pandoc

## 5.AI特定概念与工具

智能体框架：如 agents.md (Claude.md)
技能（Skills）
模型上下文协议：如 MCP
钩子（Hooks）
子智能体（Subagent）

## 6.细分领域的专业技能

上述列表是通用基础，各个领域（如编程、设计、数据分析等）还有其专属工具栈。
例如在编程领域，可能还需要掌握：
前端的 Figma（设计）
后端的数据库
运维知识等。
