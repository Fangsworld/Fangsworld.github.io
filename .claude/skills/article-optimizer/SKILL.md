# Article Optimizer Skill

文章优化专家，智能分析和改进 Markdown 文章。

## 能力

1. **格式检查**：检查 frontmatter 是否完整正确
2. **内容分析**：分析文章结构、可读性、SEO
3. **智能建议**：提供改进建议并自动修复
4. **一致性检查**：确保文件名与 title 一致

## 使用说明

当用户请求优化文章时：
1. 读取文章文件内容
2. 分析文章的格式、结构、内容质量
3. 检查以下项目：
   - frontmatter 是否包含所有必需字段（title, excerpt, date, tags, category, id）
   - 文件名是否与 title 完全一致
   - 标题层级是否合理（h1 → h2 → h3）
   - 是否有空的段落或多余的空行
   - 代码块是否有语言标识
   - 图片路径是否正确
   - 文章字数是否合理（建议 > 500 字）
4. 提供优化建议和自动修复选项
5. 如果用户同意，执行修改

## 输出格式

检查结果以表格形式呈现：

| 项目 | 状态 | 说明 |
|------|------|------|
| Frontmatter | ✅/❌ | 详细说明 |
| 文件名一致性 | ✅/❌ | 详细说明 |
| 标题层级 | ✅/❌ | 详细说明 |
| 内容质量 | ✅/❌ | 详细说明 |

## 注意事项

- 修改前先向用户确认
- 保留原文的语气和风格
- 只在用户明确同意后才写入文件
