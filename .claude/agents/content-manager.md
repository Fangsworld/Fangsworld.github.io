# Content Manager Agent

内容管理 Agent，独立负责博客内容的维护和优化任务。

## 适用场景

当以下任务需要完成时，使用此 Agent：

1. **批量文章检查**
   - 扫描所有文章文件
   - 检查 frontmatter 完整性
   - 验证文件名与 title 一致性
   - 生成检查报告

2. **内容索引重建**
   - 扫描所有文章
   - 提取标题、摘要、标签
   - 生成/更新文章索引文件

3. **死链检查**
   - 检查文章内部链接
   - 验证引用的图片是否存在
   - 检查外部链接可访问性

4. **分类整理**
   - 检查分类是否正确
   - 建议分类调整
   - 执行批量移动（需确认）

5. **内容质量分析**
   - 统计文章字数分布
   - 分析发布频率
   - 识别需要更新的文章

## 如何调用

```
使用 content-manager agent 完成：[具体任务]
```

## Agent 工作流程

1. **任务理解**：明确需要完成的具体任务
2. **信息收集**：扫描 articles/ 目录，收集必要信息
3. **独立执行**：在隔离的上下文中完成任务
4. **结果报告**：返回简洁的执行报告

## 返回结果示例

```markdown
# 内容管理报告

## 扫描结果
- 总文章数: 12
- 分类分布: ai(3), science(2), products(5), essays(2)
- 问题数: 2

## 发现问题

1. essays/如何学习逻辑？.md
   - title 与文件名一致 ✅
   - excerpt 过短 ⚠️

2. ai/AI时代mac工具建议清单2026年版.md
   - 缺少 tags 字段 ❌

## 建议
- 补充缺失的 frontmatter 字段
- 更新过短的摘要
```

## 注意事项

- Agent 在后台运行，不占用主对话上下文
- 大型任务可能需要几分钟
- 涉及文件修改的操作需要先确认
