## 1. 什么是数据库？

### 简单理解

数据库就像一个**超级强大的电子表格系统**，但比 Excel 强大得多：

```
┌─────────────────────────────────────────────────────────────┐
│                    电子表格 vs 数据库                       │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  📊 Excel 电子表格          💾 数据库                      │
│  ├─ 适合小数据量          ├─ 适合大量数据                  │
│  ├─ 单用户使用            ├─ 多用户同时访问                 │
│  ├─ 容易丢失数据          ├─ 数据安全可靠                   │
│  ├─ 查询功能有限          ├─ 强大的查询能力                 │
│  └─ 没有关系管理          └─ 支持复杂关系                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 为什么需要数据库？

#### 场景 1：存储博客数据

**不用数据库：**
```javascript
// 数据存在文件中
const articles = [
  { id: 1, title: "文章1", views: 100 },
  { id: 2, title: "文章2", views: 200 },
];

// 问题：
// ❌ 每次读取都要加载整个文件
// ❌ 并发写入会丢失数据
// ❌ 查询功能有限
// ❌ 数据容易丢失
```

**使用数据库：**
```sql
-- 只查询需要的数据
SELECT title, views FROM articles WHERE id = 1;

-- 优点：
-- ✅ 只读取需要的数据
-- ✅ 支持并发访问
-- ✅ 强大的查询功能
-- ✅ 数据安全可靠
```

## 2. PostgreSQL 简介

### 什么是 PostgreSQL？

PostgreSQL（简称 Postgres）是世界上最先进的开源关系型数据库。

```
┌─────────────────────────────────────────────────────────────┐
│                  PostgreSQL 特性                            │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ✅ 开源免费 - 完全免费，无版权限制                         │
│  ✅ 功能强大 - 支持复杂查询、事务、索引                      │
│  ✅ 高度可靠 - 数据安全，不易损坏                            │
│  ✅ 可扩展性 - 支持自定义函数、数据类型                      │
│  ✅ 社区活跃 - 大量文档和教程                                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 数据类型

```sql
-- 常用数据类型
INTEGER      -- 整数（1, 2, 100）
TEXT         -- 文本（任意长度）
TIMESTAMP    -- 时间戳（自动记录时间）
BOOLEAN      -- 布尔值（true/false）
ARRAY        -- 数组
JSONB        -- JSON 数据（支持查询）

-- 示例
CREATE TABLE users (
  id INTEGER PRIMARY KEY,
  name TEXT NOT NULL,
  email TEXT UNIQUE,
  age INTEGER,
  is_active BOOLEAN DEFAULT true,
  created_at TIMESTAMP DEFAULT NOW()
);
```

## 3. Neon 简介

### 什么是 Neon？

Neon 是一个**无服务器 PostgreSQL** 平台。

```
┌─────────────────────────────────────────────────────────────┐
│            传统 PostgreSQL vs Neon                          │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  传统 PostgreSQL            Neon                            │
│  ├─ 需要自己的服务器      ├─ 无服务器，自动扩缩容           │
│  ├─ 需要手动维护          ├─ 自动维护和升级                 │
│  ├─ 按固定规格付费        ├─ 按实际使用量付费               │
│  ├─ 需要配置备份          ├─ 自动备份                        │
│  └─ 需要管理连接池        └─ 自动管理连接                   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### Neon 的优势

**1. 免费额度充足**
```
免费项目包括：
├─ 0.5 GB 存储
├─ 300 小时计算时间/月
└─ 无限分支（用于开发测试）

适合个人博客、小型项目
```

**2. 自动扩缩容**
```javascript
// 访问量少时
// → 自动减少资源，节省费用

// 访问量暴增时
// → 自动增加资源，保证可用性
```

**3. 数据库分支**
```bash
# 创建开发分支
neon branches create my-feature

# 测试新功能
# → 不会影响主数据库

# 合并到主库
neon branches merge my-feature
```

## 4. Drizzle ORM 简介

### 什么是 ORM？

ORM（Object-Relational Mapping）对象关系映射，让你用 **JavaScript 对象** 的方式操作数据库。

```
┌─────────────────────────────────────────────────────────────┐
│                  不用 ORM vs 用 ORM                         │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ❌ 直接写 SQL                                             │
│  const result = await db.query(                            │
│    `SELECT * FROM users WHERE name = '${userName}'`         │
│  );                                                        │
│  // 问题：SQL 注入风险、类型不安全                          │
│                                                             │
│  ✅ 使用 ORM                                               │
│  const result = await db.select()                          │
│    .from(users)                                            │
│    .where(eq(users.name, userName));                       │
│  // 优点：类型安全、防止注入、代码提示                       │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### Drizzle ORM 的优势

**1. 类型安全**
```typescript
import { articles } from '@/db/schema';

// TypeScript 自动推断类型
const result = await db.select({
  id: articles.id,
  title: articles.title,
  views: articles.views,
}).from(articles);

// 类型：{ id: number; title: string; views: number; }[]
```

**2. 代码提示**
```typescript
// IDE 会自动提示可用的字段
articles.  // → id, title, slug, views, likes, ...

// 编译时检查错误
articles.nonExistentField  // ❌ TypeScript 报错
```

**3. 数据库无关**
```typescript
// 同样的代码可以用于不同的数据库
// PostgreSQL, MySQL, SQLite...
```

## 5. 它们如何协同工作？

```
┌─────────────────────────────────────────────────────────────┐
│                    数据访问流程                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  你的代码                                                    │
│    ↓                                                        │
│  Drizzle ORM (类型安全的查询)                                │
│    ↓                                                        │
│  Neon PostgreSQL (存储数据)                                  │
│                                                             │
│  示例：                                                      │
│  ┌─────────────────────────────────────────────────────┐  │
│  │ // 1. 你的代码                                       │  │
│  │ const article = await getArticle('my-slug');         │  │
│  │                                                      │  │
│  │ // 2. Drizzle ORM 转换                              │  │
│  │ db.select().from(articles)                          │  │
│  │   .where(eq(articles.slug, 'my-slug'));             │  │
│  │                                                      │  │
│  │ // 3. 生成 SQL                                      │  │
│  │ SELECT * FROM articles WHERE slug = 'my-slug';      │  │
│  │                                                      │  │
│  │ // 4. Neon 执行并返回数据                            │  │
│  │ { id: 1, slug: 'my-slug', title: '...', ... }      │  │
│  └─────────────────────────────────────────────────────┘  │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 6. 实际项目中的应用

### 你的博客项目使用的技术栈

```typescript
// 数据库结构
db/
├── schema.ts      // 定义数据表（articles, comments, likes）
├── index.ts       // 数据库连接
└── queries.ts     // 查询函数

// 示例：获取文章统计
async function getArticleStats(slug: string) {
  const result = await db.select({
    views: articles.views,
    likes: articles.likes,
    comments: articles.commentCount,
  })
  .from(articles)
  .where(eq(articles.slug, slug));

  return result[0];
}
```

## 7. 核心概念总结

| 概念 | 说明 | 类比 |
|------|------|------|
| **数据库** | 存储数据的系统 | 超级电子表格 |
| **PostgreSQL** | 关系型数据库软件 | Excel 专业版 |
| **Neon** | 云端 PostgreSQL 服务 | Google Sheets |
| **ORM** | 数据库映射工具 | 翻译器 |
| **Drizzle** | 类型安全的 ORM | 带智能提示的翻译器 |
