# 🚀 快速开始指南

这是一个 **5 分钟快速开始指南**，帮你快速上手 Neon + Drizzle。

---

## 前置条件

- ✅ Node.js 已安装
- ✅ Git 已安装
- ✅ 一个 GitHub 账户

---

## 步骤 1：创建 Neon 数据库（2 分钟）

1. **访问 Neon**
   - 打开 [https://neon.tech](https://neon.tech)
   - 点击 "Sign up" → "Continue with GitHub"

2. **创建项目**
   - 点击 "Create a project"
   - 项目名：`my-blog`
   - 区域：选择最近的区域
   - 点击 "Create project"

3. **复制连接字符串**
   ```
   postgresql://username:password@hostname/database?sslmode=require
   ```

---

## 步骤 2：配置项目（1 分钟）

1. **创建环境变量文件**
   ```bash
   # 在项目根目录
   touch .env.local
   ```

2. **添加数据库连接**
   ```env
   # .env.local
   DATABASE_URL="你的连接字符串"
   ```

3. **验证配置**
   ```bash
   npm run db:health
   ```

---

## 步骤 3：查看数据（1 分钟）

```bash
# 打开可视化界面
npm run db:studio

# 在浏览器访问
# https://local.drizzle.studio
```

你会看到：
- 📊 articles（16 行）
- 💬 comments（2 行）
- ❤️ likes（2 行）

---

## 步骤 4：执行查询（1 分钟）

### 使用 Studio

1. 点击任意表
2. 点击 "+ Add new record"
3. 输入数据
4. 点击 "Save"

### 使用代码

创建 `test.ts`：
```typescript
import { db } from './db';
import { articles } from './db/schema';

// 查询所有文章
const all = await db.select().from(articles);
console.log(all);

// 插入新文章
const [newArticle] = await db.insert(articles)
  .values({
    slug: 'test-' + Date.now(),
    title: '测试文章',
    category: 'reading',
  })
  .returning();

console.log('Created:', newArticle);
```

运行：
```bash
npx tsx test.ts
```
