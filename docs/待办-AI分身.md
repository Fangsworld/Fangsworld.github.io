# 待办：网站 AI 分身

记录日期：2026-11-24
状态：待启动，暂不开发

## 目标

在个人网站部署基于「一念」能力的 AI 分身，让访客通过对话了解宇文平野的经历、观点和作品，支持模拟面试与追问。逐步校准本人判断方式与表达习惯，不承诺回答完全等同于本人即时想法。

## 第一版范围

- [ ] 检查一念现有接口、身份、权限和部署方式，确定可复用部分。
- [ ] 首页提供「与我的 AI 分身聊聊」入口，进入独立对话页。
- [ ] 清楚标注 AI 分身身份，支持第一人称回答和连续追问。
- [ ] 建立独立公开资料库：网站文章、作品介绍、本人确认的经历与项目案例。
- [ ] 补充面试所需案例：本人职责、采取的行动、结果、失败与复盘。
- [ ] 实现资料检索、回答生成、原文与作品出处展示。
- [ ] 准备约 30 个面试及观点问题，由本人逐条修订回答，形成校准材料。
- [ ] 添加请求限额、费用上限和必要的滥用防护。

## 回答与数据边界

- 有资料依据的经历、观点直接回答，并提供出处。
- 对新问题的推演与本人已明确表达的观点作出区分。
- 没有依据的经历、业绩不编造；薪资、合作条件等不代本人承诺。
- 公开分身与一念私人聊天、记忆、工具权限隔离，仅使用主动选定的公开资料。
- 访客输入不自动写入本人的长期观点或记忆。
- 本人修订经确认后才纳入校准资料；访客对话的保存方式与告知需在上线前确定。

## 推荐启动顺序

1. 核对一念接口，以文章和作品做出内部可聊天版本。
2. 本人完成问题测试、修订及经历案例补充。
3. 验证资料引用、无依据问题处理、隐私隔离和费用限制。
4. 确认效果后再公开上线。
