## 2. 配置项目

### 步骤 1：安装依赖

```bash
# 安装 Drizzle ORM 和 Neon 客户端
npm install drizzle-orm @neondatabase/serverless

# 安装 Drizzle Kit（用于迁移）
npm install -D drizzle-kit

# 安装 dotenv（用于环境变量）
npm install dotenv
```

### 步骤 2：配置环境变量

创建 `.env.local` 文件：

```bash
# 在项目根目录执行
touch .env.local
```

添加数据库连接字符串：

```env
# .env.local
DATABASE_URL="postgresql://username:password@hostname/database?sslmode=require"
```

**⚠️ 重要：**
- 不要将 `.env.local` 提交到 Git
- 它已经包含在 `.gitignore` 中

### 步骤 3：创建 Drizzle 配置

创建 `drizzle.config.ts`：

```typescript
import { defineConfig } from 'drizzle-kit';
import { config } from 'dotenv';
import { resolve } from 'path';

// 加载 .env.local 文件
config({ path: resolve(process.cwd(), '.env.local') });

export default defineConfig({
  schema: './db/schema.ts',           // Schema 文件位置
  out: './db/migrations',             // 迁移文件位置
  dialect: 'postgresql',              // 数据库类型
  dbCredentials: {
    url: process.env.DATABASE_URL!,   // 数据库连接字符串
  },
});
```

## 3. 创建数据库 Schema

### 步骤 1：创建目录结构

```bash
mkdir -p db
```

### 步骤 2：定义 Schema

创建 `db/schema.ts`：

```typescript
import { pgTable, serial, text, integer, timestamp, index } from 'drizzle-orm/pg-core';

// 文章表
export const articles = pgTable('articles', {
  id: serial('id').primaryKey(),
  slug: text('slug').notNull().unique(),
  title: text('title').notNull(),
  content: text('content'),
  views: integer('views').notNull().default(0),
  createdAt: timestamp('created_at').notNull().defaultNow(),
}, (table) => ({
  slugIdx: index('articles_slug_idx').on(table.slug),
}));

// 类型定义
export type Article = typeof articles.$inferSelect;
export type NewArticle = typeof articles.$inferInsert;
```

### 步骤 3：创建数据库连接

创建 `db/index.ts`：

```typescript
import { neon } from '@neondatabase/serverless';
import { drizzle } from 'drizzle-orm/neon-http';
import * as schema from './schema';

if (!process.env.DATABASE_URL) {
  throw new Error('DATABASE_URL environment variable is not set');
}

const sql = neon(process.env.DATABASE_URL);
export const db = drizzle(sql, { schema });
```

## 4. 生成并执行迁移

### 步骤 1：生成迁移文件

```bash
npm run db:generate
```

这会在 `db/migrations/` 创建迁移文件：

```sql
-- db/migrations/0001_init.sql
CREATE TABLE IF NOT EXISTS "articles" (
  "id" serial PRIMARY KEY,
  "slug" text NOT NULL UNIQUE,
  "title" text NOT NULL,
  "content" text,
  "views" integer DEFAULT 0 NOT NULL,
  "created_at" timestamp DEFAULT now() NOT NULL
);

CREATE INDEX IF NOT EXISTS "articles_slug_idx" ON "articles" ("slug");
```

### 步骤 2：推送到数据库（开发环境）

```bash
npm run db:push
```

**或者使用 Drizzle Studio：**

```bash
npm run db:studio
```

在浏览器中 https://local.drizzle.studio 会自动创建表。

## 5. 测试连接

### 创建测试脚本

创建 `scripts/test-db.ts`：

```typescript
#!/usr/bin/env tsx
import { config } from 'dotenv';
import { resolve } from 'path';
config({ path: resolve(process.cwd(), '.env.local') });

import { db } from '../db';
import { articles } from '../db/schema';

async function test() {
  console.log('🔍 测试数据库连接...\n');

  // 测试查询
  const result = await db.select().from(articles);
  console.log('✅ 连接成功！');
  console.log(`📊 当前文章数：${result.length}\n`);

  // 插入测试数据
  const [newArticle] = await db.insert(articles)
    .values({
      slug: 'test-article',
      title: '测试文章',
      content: '这是一篇测试文章',
    })
    .returning();

  console.log('✅ 插入成功：', newArticle);

  // 查询测试数据
  const found = await db.select()
    .from(articles)
    .where(eq(articles.slug, 'test-article'));

  console.log('✅ 查询成功：', found);
}

test().catch(console.error);
```

### 运行测试

```bash
npx tsx scripts/test-db.ts
```

**预期输出：**
```
🔍 测试数据库连接...

✅ 连接成功！
📊 当前文章数：0

✅ 插入成功：{ id: 1, slug: 'test-article', ... }
✅ 查询成功：[{ id: 1, slug: 'test-article', ... }]
```

## 7. 常见问题

### ❌ 问题 1：DATABASE_URL 未定义

**错误：**
```
Error: DATABASE_URL environment variable is not set
```

**解决：**
```bash
# 1. 检查 .env.local 是否存在
cat .env.local

# 2. 确认格式正确
cat .env.local | grep DATABASE_URL

# 3. 重启开发服务器
npm run dev
```

### ❌ 问题 2：连接失败

**错误：**
```
Error: Connection refused
```

**解决：**
1. 确认 Neon 数据库在线
2. 检查连接字符串是否正确
3. 确认网络连接

### ❌ 问题 3：表已存在

**错误：**
```
Error: relation "articles" already exists
```

**解决：**
```bash
# 使用 push 代替 migrate（开发环境）
npm run db:push

# 或删除现有表后重新创建
# 在 Neon SQL Editor 中执行
DROP TABLE IF EXISTS articles CASCADE;
```
