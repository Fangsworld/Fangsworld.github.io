# 网站统计查看指南

本文档介绍如何查看和分析你的网站统计数据。

---

## 🎯 快速查看统计

### 方法 1：使用命令行（推荐）

```bash
npm run stats:view
```

**输出内容：**
- 📈 基础统计（文章数、浏览量、点赞数、评论数）
- 🔥 热门文章 Top 10
- 📂 分类统计
- ❤️ 最受喜爱文章
- 💬 讨论最热烈文章
- 🕐 最近发布文章
- 💭 评论统计

### 方法 2：使用 Drizzle Studio

```bash
npm run db:studio
```

在浏览器中访问 https://local.drizzle.studio，你可以：
- 查看所有表数据
- 编辑记录
- 筛选和排序
- 导出数据

### 方法 3：使用健康检查

```bash
npm run db:health
```

查看数据库健康状况和性能指标。

## 📊 统计数据解读

### 基础统计

```
📈 基础统计:
  📝 文章总数: 16
  👁️  总浏览量: 63
  ❤️  总点赞数: 2
  💬 总评论数: 0
  📂 分类数量: 4
```

**解读：**
- **文章总数**：你已发布的内容数量
- **总浏览量**：所有文章的浏览次数总和
- **总点赞数**：所有文章获得的点赞总数
- **总评论数**：已批准的评论数量
- **分类数量**：你使用的分类数量

### 热门文章

```
🔥 热门文章 Top 10:
  🥇 《如何阅读一本书》精要...
      👁️ 30 | ❤️ 1 | 💬 1 | 📂 reading
```

**解读：**
- **排名**：按浏览量排序
- **浏览量**：文章被查看的次数
- **点赞数**：文章获得的点赞
- **评论数**：文章的评论数量
- **分类**：文章所属分类

### 分类统计

```
📂 分类统计:
  📚 阅读:
     文章数: 13 | 浏览: 46 | 点赞: 2
```

**解读：**
- 每个分类的文章数量
- 每个分类的总浏览量
- 每个分类的总点赞数

**用途：**
- 了解哪个分类最受欢迎
- 决定今后内容方向
- 平衡各分类内容

### 点赞率

```
❤️ 最受喜爱文章 Top 5:
  1. 《原则》实践指南...
     ❤️ 1 | 👁️ 4 | 点赞率: 25.00%
```

**解读：**
- **点赞率 = 点赞数 / 浏览量 × 100%**
- 反映文章质量和读者满意度
- 点赞率高说明内容受欢迎

**参考标准：**
- 优秀：> 10%
- 良好：5% - 10%
- 一般：1% - 5%
- 需改进：< 1%

### 评论统计

```
💭 评论统计:
  ✅ 已批准: 0
  ⏳ 待审核: 2
  ❌ 已拒绝: 0
```

**解读：**
- **已批准**：显示在网站上的评论
- **待审核**：等待审核的评论（不显示）
- **已拒绝**：被拒绝的评论（不显示）

## 🔍 高级分析

### 1. 内容表现分析

```bash
npm run stats:view
```

**关注指标：**
- ✅ 高浏览量 + 高点赞率 = 优质内容
- ⚠️ 高浏览量 + 低点赞率 = 标题党或内容不符
- 📈 低浏览量 + 高点赞率 = 被埋没的好内容
- ❌ 低浏览量 + 低点赞率 = 需要改进

### 2. 内容方向分析

查看分类统计，决定：
- 哪个分类最受欢迎（增加内容）
- 哪个分类需要补充（平衡发展）
- 读者偏好类型（数据驱动决策）

### 3. 发布时间优化

结合"最近发布文章"和浏览量：
- 哪些时间段发布效果更好
- 新旧文章的浏览量对比
- 内容生命周期分析

**查看分类统计：**
```bash

**不平衡的例子：**
```

## 🎨 可视化统计（可选）

### 1. 使用图表库

安装依赖：
```bash
npm install recharts
```

创建统计图表组件：
```typescript
// components/stats/Chart.tsx
import { BarChart, Bar, XAxis, YAxis, Tooltip } from 'recharts';

const data = [
  { category: '阅读', views: 46 },
  { category: '逻辑', views: 9 },
  { category: '写作', views: 4 },
];

export function CategoryChart() {
  return (
    <BarChart width={400} height={300} data={data}>
      <XAxis dataKey="category" />
      <YAxis />
      <Tooltip />
      <Bar dataKey="views" fill="#0cbfa0" />
    </BarChart>
  );
}
```

### 2. 集成 Google Analytics

**步骤：**

1. **创建 GA 账户**
   - 访问 [https://analytics.google.com](https://analytics.google.com)
   - 创建媒体资源

2. **获取跟踪 ID**
   - 格式：`G-XXXXXXXXXX`

3. **添加到 Next.js**

在 `app/layout.tsx` 中添加：
```typescript
import Script from 'next/script';

export default function RootLayout({ children }) {
  return (
    <html>
      <head>
        <Script
          src="https://www.googletagmanager.com/gtag/js?id=G-XXXXXXXXXX"
          strategy="afterInteractive"
        />
        <Script id="google-analytics" strategy="afterInteractive">
          {`
            window.dataLayer = window.dataLayer || [];
            function gtag(){dataLayer.push(arguments);}
            gtag('js', new Date());
            gtag('config', 'G-XXXXXXXXXX');
          `}
        </Script>
      </head>
      <body>{children}</body>
    </html>
  );
}
```

4. **查看统计**
   - 访问 Google Analytics Dashboard
   - 查看：实时访客、页面浏览、用户行为

### 3. 使用 Vercel Analytics

**安装：**

## 🔧 自定义统计

### 添加新的统计指标

编辑 `scripts/view-stats.ts`：

```typescript
// 添加平均浏览量
const avgViews = await sql`
  SELECT ROUND(AVG(views), 2) as avg_views
  FROM articles
  WHERE views > 0
`;
console.log('  📊 平均浏览量:', avgViews[0].avg_views);

// 添加今日活跃文章
const todayActive = await sql`
  SELECT COUNT(*) as count
  FROM articles
  WHERE updated_at > NOW() - INTERVAL '24 hours'
`;
console.log('  🆕 今日活跃:', todayActive[0].count);
```

### 导出统计数据

```typescript
// 添加到 view-stats.ts
import { writeFileSync } from 'fs';

const stats = {
  basic: basic[0],
  topArticles: topArticles,
  categoryStats: categoryStats,
  timestamp: new Date().toISOString(),
};

writeFileSync(
  'stats.json',
  JSON.stringify(stats, null, 2)
);
console.log('  📄 统计已导出到 stats.json');
```
